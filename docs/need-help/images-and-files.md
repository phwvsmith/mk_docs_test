# Images and Files

This guide explains how to add images and files to your pages so they display correctly on the site.

---

## 🖼️ Adding Images

### Step 1: Upload the image

1. Go to the appropriate folder (e.g. `docs/images/`)
2. Click **Add file → Upload files**
3. Upload your image
4. Click **Commit changes**

---

### Step 2: Add the image to your page

Use the relative path to reference the image:

../images/example.png

---

## ✅ Good Practices for Images

- Use clear and descriptive file names  
- Keep file names simple (no spaces if possible)  
- Use lowercase (recommended)  
- Store images in a dedicated folder (e.g. `images/`)  

Example:

data-flow-diagram.png

---

## ⚠️ Common Issues with Images

### ❌ Image not showing

**Possible causes:**
- File not uploaded
- Incorrect path
- File name mismatch (case-sensitive)

**Fix:**
- Confirm the file exists in the repository
- Check the path matches exactly
- Ensure spelling and casing are correct

---

## 📂 Adding Files (e.g. PDFs, documents)

### Step 1: Upload the file

- Navigate to the correct folder (e.g. `docs/files/`)
- Click **Add file → Upload files**
- Upload your file
- Click **Commit changes**

---

### Step 2: Link the file

Use the relative path:

../files/example.pdf

---

## ✅ Good Practices for Files

- Use clear file names  
- Organise files into folders (`images/`, `files/`, etc.)  
- Avoid duplicate files  
- Keep file sizes reasonable  

---

## 🔗 Linking Files in Text

You can include files in your content like this:

Download the file here: ../files/example.pdf

---

## 🧠 Folder Structure Example

docs/

- images/
  - diagram.png
  - chart.png

- files/
  - guide.pdf
  - template.xlsx

---

## ✅ Quick Checklist

Before saving your page:

- Is the file uploaded?  
- Is the path correct?  
- Does the file name match exactly?  
- Is the file placed in the right folder?  

---

## 💡 Tip

If something doesn’t display correctly, it’s usually due to the file path or file name.  
Double-check both before committing changes.
