# Formatting Guide

This site uses **Markdown** for writing content.  
You don’t need any technical background—just follow these simple patterns.

---

## 📌 Headings

Use headings to organise your content clearly.

# Page Title (use once per page)

## Section Heading

### Sub-section

✅ Use headings to break content into sections  
❌ Don’t skip levels (e.g. jumping from `#` to `####`)

---

## 📝 Paragraphs

Keep paragraphs short and readable.

This is a paragraph.

This is another paragraph.

✅ Always leave a blank line between paragraphs  

---

## ✅ Lists

### Bullet Lists

- Item one
- Item two
- Item three

### Numbered Lists

1. Step one
2. Step two
3. Step three

✅ Use lists instead of long paragraphs  

---

## 💻 Code Blocks

Use code blocks to display commands or code clearly.

Example:

pip install mkdocs

(If using Markdown source, wrap with three backticks)

✅ Keeps formatting clean and readable  

---

## 🔗 Links

Example external link:

https://example.com

Example internal link:

../index.md

✅ Use descriptive links where possible  

---

## 🖼️ Images

Example:

../images/example.png

✅ Make sure:
- Image file has been uploaded
- Path is correct
- File name matches exactly (case-sensitive)

---

## 📊 Tables

| Name | Role |
|------|------|
| Alex | Analyst |
| Sam  | Engineer |

✅ Keep tables simple and aligned  

---

## 💡 Notes, Tips & Warnings

You can highlight important information:

!!! note
    This is a note

!!! tip
    This is a useful tip

!!! warning
    This is a warning

✅ Use these for important or helpful information  

---

## ✏️ Text Formatting

Bold text:

**Bold text**

Italic text:

*Italic text*

✅ Use bold for emphasis  
✅ Use italics sparingly  

---

## 🧠 Best Practices

✅ Keep content simple and readable  
✅ Use headings to structure your content  
✅ Break content into sections  
✅ Prefer lists over long paragraphs  
✅ Add examples where helpful  

---

## ⚠️ Common Mistakes

❌ Missing blank lines  
❌ Incorrect heading levels  
❌ Broken image paths  
❌ Large blocks of text without structure  
❌ Incorrect list indentation
