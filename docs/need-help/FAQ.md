# FAQ

This section answers common questions about using and editing the site.

---

## ❓ Do I need Git or technical knowledge to edit pages?

No.  

✅ You can edit pages directly in the browser  
✅ Just click **Edit**, make your changes, and commit  

The system handles everything else automatically.

---

## ❓ How long does it take for changes to appear?

Most changes are published within:

✅ A few seconds  
✅ Up to 1–2 minutes in some cases  

If you don’t see your update:
- Refresh the page (Ctrl + F5)

---

## ❓ What happens after I click “Commit changes”?

When you commit:

1. A change request is created  
2. The system checks your update  
3. It is merged and published automatically  

You don’t need to do anything else.

---

## ❓ Why didn’t my changes get published?

This usually happens when:

- Someone else edited the same page at the same time  
- The system couldn’t safely combine both updates  

👉 See **Common Issues** for what to do next  

---

## ❓ Can I edit someone else’s page?

Yes.  

✅ This is a shared knowledge base  
✅ Anyone can improve or update content  

---

## ❓ Can I undo a change?

Yes.

- You can edit the page again and correct it  
- Or revert changes using GitHub if needed  

---

## ❓ How do I create a new page?

- Go to the repository  
- Click **Add file → Create new file**  
- Add your content  
- Update the `.pages` file to include it in navigation  

👉 See **Editing and Adding Pages** for details  

---

## ❓ Why is my image not showing?

Common causes:

- File not uploaded  
- Incorrect path  
- File name mismatch  

👉 See **Images and Files** for guidance  

---

## ❓ Why does my formatting look wrong?

Common causes:

- Missing blank lines  
- Incorrect headings  
- List indentation issues  

👉 See **Formatting Guide** for examples  

---

## ❓ Where should I put images and files?

- Images → `images/` folder  
- Documents (PDFs, etc.) → `files/` folder  

Keep things organised and easy to find.

---

## ❓ When should I create a new page vs edit an existing one?

### Edit existing page if:
- The topic already exists  
- You are improving content  

### Create a new page if:
- The topic is new  
- The content would make an existing page too long  

---

## ❓ What if I make a mistake?

No problem ✅

- You can edit the page again and fix it  
- All changes are tracked and can be corrected  

---

## ❓ Who do I contact if I’m stuck?

If you can’t resolve your issue:

- Check **Common Issues** first  
- Then contact the support team (see **Who to Contact**)  

---

## 💡 Tip

If something doesn’t work as expected, try again after refreshing or reapplying your changes.  
Most issues are temporary and resolve quickly.
