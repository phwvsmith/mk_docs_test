# 🚀 How to Edit & Add : Data Analysts

Welcome! This guide shows you how to view and update documentation easily — no Git or local setup required.

👉 Found something outdated? Fix it in seconds using the steps below.

---

## 🧠 Before you start

- ❌ You do NOT need to create branches manually  
- ❌ You do NOT need to install anything  
- ✅ Everything can be done in the browser
- ✅ You write, we take care of the rest

---


## 👥 Who is this for?

- Analysts
- Users who want to improve or update documentation
- Anyone who prefers a simple, browser-based workflow

---

## 🎯 What you’ll achieve

By the end of this guide, you will:

- ✅ Know how to update documentation pages  
- ✅ Be able to submit changes without using Git commands  
- ✅ Understand how your changes go live  

---

## 🟢 Recommended: Edit directly in the browser (no setup needed)

### ✏️ Go to the documentation site

👉 [NDAP Knowledge Hub](https://Public-Health-Wales.github.io/ndap_central_doc_repo/)

---

### ✏️ Navigate to the page you want to edit

- Find the page you want to improve  
- Read through the content  

---

### ✏️ Click **“Edit this page”**

- At the top/right of the page  
- This opens the page in GitHub  

---

### ✏️ Make your changes

- Edit text directly in the browser  
- Use the **Preview** tab to check formatting  

---

### ✏️ Submit your update

Scroll down and click **"Propose changes"**

👉 This will:

- Automatically create a branch ✅  
- Create a Pull Request (PR) ✅  

---

### ✅ What happens next

- Let us handle the rest while you go and have a cuppa ☕ ✅ 

---


## ✅ Don’t worry about making mistakes

- Changes are reviewed before going live  
- If something needs fixing, we’ll help ✅  

Just share what you know — even small improvements help!
